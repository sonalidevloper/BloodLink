# 🩸 BloodLink — Real-Time Blood Donation Platform

> **Real-time blood donation app** that connects **donors** and **patients** instantly using **location** and **blood type**.  
> ⚡ GPS-based matching • 🧭 Simple UI • ❤️ Fast, lifesaving support

---

## 📌 Overview

**BloodLink** is a web-based platform designed to reduce response time in blood emergencies by helping users quickly find compatible donors nearby.

It enables:

- 👤 **Donors** to register and share blood type/location
- 🏥 **Patients / Requesters** to find urgent compatible donors
- 📍 **Location-aware matching** for faster assistance
- 🩸 **Blood group filtering** for accurate donor selection

---

## ✨ Features

- 🧾 Donor registration and profile management  
- 🔎 Search donors by blood group  
- 📍 GPS/location-based donor matching  
- ⚡ Real-time availability flow (quick connect)  
- 📱 Clean, responsive interface for fast emergency usage

## 🧪 How It Works

1. 📝 A donor registers with blood type and location.
2. 🚨 A patient/requester raises a blood request.
3. 📡 BloodLink matches nearby compatible donors using location + blood group.
4. 📲 Requester quickly connects with available donors.

## 🚀 Getting Started

### 1) Clone the repository


Since this is an HTML + JavaScript project, you can run it directly:
